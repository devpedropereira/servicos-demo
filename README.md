# Demonstração: página de serviços com agendamento

Demonstração comercial de uma página para negócios de serviço, usando como exemplo uma estética automotiva fictícia.

A página demonstra:

- serviços e pacotes com preços de referência;
- solicitação estruturada pelo WhatsApp;
- agendamento online **apenas demonstrativo**.

Todos os dados apresentados são **fictícios**: nome, endereço, telefone, avaliações e horários. As fotos são ilustrativas (Unsplash).

Nenhum dado é enviado ou salvo. A agenda é simulada, e a solicitação abre o WhatsApp do próprio visitante sem um número definido.

Página: https://devpedropereira.github.io/servicos-demo/
